# BOM公式系统 — 卡片式设计方案

---

## 一、设计目标

| 要求 | 说明 |
|------|------|
| 替代 | 当前表格+弹窗模式 |
| 主交互 | 卡片列表 + 点击展开编辑 |
| 每种模式 | 有自己的专属编辑器布局 |
| 无弹窗 | 所有编辑在行内完成 |
| 即时保存 | 切换模式/编辑公式后一键保存 |

## 三、卡片结构（通用）

### 3.1 折叠状态（始终可见）

每个BOM卡片折叠时显示5个信息块：

```
┌────────────────────────────────────────────────────────────┐
│ ⚙️ 物料名称     ×[数量] [单位]    [模式药丸]    [公式摘要]  [▶]
│                                                                  
│ ────┬──────      ───┬───  ───┬───  ─────┬───────  ──┬──
│     │               │        │           │          │
│  零件名+图标  静态或计算值  件/台/个   📐⚡等图标   最主要公式 展开按钮
│  (始终显示)    (灰色=静态)              (显示激活的模式) 或映射摘要 
└────────────────────────────────────────────────────────────┘
```

**公式摘要规则：**

| 模式组合 | 摘要显示 | 示例 |
|---------|---------|------|
| 仅📐数量公式 | 完整公式 | `CEIL(长度/500)` |
| 📐 + ⚡ | 数量公式，条件标记 | `CEIL(...) ⚡条件` |
| 🎯候选 | 候选数 | `3个候选件` |
| 🧬变体 | 模板名 | `模板: 立柱-参数化` |
| 📝规格 | 字段数 | `4个规格字段` |
| 🏢供应商 | 规则数 | `2条供应商规则` |
| 标准（无公式） | 灰色「标准」 | `— 标准` |

**数量显示规则：**
- 白色背景 = 静态数量（来自BomItem）
- 蓝色背景 = 有公式，显示计算结果

### 3.2 展开后编辑器（点击展开）

展开后的编辑区包含**三层内容**：

```
┌────────────────────────────────────────────────────────────┐
│ 模式切换栏（toggle button group）                            │
│ [📐 数量公式] [⚡ 条件] [🎯 候选] [🧬 变体] [📝 规格] [🏢 供应商]│
│  ─────┬─────  ──┬──  ──┬──  ──┬──  ──┬──  ────┬────       │
│       │          │      │      │      │          │          │
│  ┌────┴────┐     │      │      │      │          │          │
│  │激活态   │   可点击切换，多选模式                            │
│  │蓝色高亮 │   ⚡必须与📐组合使用                               │
│  └─────────┘   🧬/📝/🏢互斥                                    │
│                                                                
│ 编辑器区（根据激活的模式动态渲染）                               │
│ ┌────────────────────────────────────────────────────────┐   │
│ │ 见下面第四节的「各模式编辑器设计」                         │   │
│ └────────────────────────────────────────────────────────┘   │
│                                                                
│ 底部操作栏                                                   │
│ 可用参数: [长度] [速度] [载重] [电机功率]                     │
│ 函数: [CEIL] [FLOOR] [IF] [AND] [OR] [LEFT] [CONCAT] [...] │
│ [💾 保存] [✓ 验证全部] [▶ 预览全部]                          │
└────────────────────────────────────────────────────────────┘
```

## 四、各模式编辑器设计

### 4.1 📐 数量公式（最常用）

```
┌────────────────────────────────────────────────────────┐
│ 📐 数量公式                                             │
│ ┌────────────────────────────────────────────────────┐ │
│ │ CEIL(param.长度 / 500) * 2                         │ │
│ └────────────────────────────────────────────────────┘ │
│ [✓验证] 结果: 10                                       │
│ ┌──────────┬──────────┬─────────┬────────┐            │
│ │ 长度=5000 │ 速度=12  │ 载重=1000│ 结果=10 │            │
│ │ [滑块调整] │          │          │        │            │
│ └──────────┴──────────┴─────────┴────────┘            │
│ 预览: 电机当前参数下 ×1 台                              │
└────────────────────────────────────────────────────────┘
```

**字段数：** 1个输入框 + 预览区

### 4.2 ⚡ 条件包含（与📐组合使用）

```
┌────────────────────────────────────────────────────────┐
│ 🔍 条件公式                                             │
│ ┌────────────────────────────────────────────────────┐ │
│ │ param.速度 > 15                                    │ │
│ └────────────────────────────────────────────────────┘ │
│ [✓验证] 结果: true (速度=12 → 不包含)                   │
│ ┌────────────────────────────┐                         │
│ │ 当前速度=12 → 不包含此项    │                         │
│ │ 如果速度=20 → 包含此项     │                         │
│ └────────────────────────────┘                         │
└────────────────────────────────────────────────────────┘
```

**字段数：** 1个输入框

### 4.3 🎯 候选零件

```
┌────────────────────────────────────────────────────────┐
│ 🎯 候选零件列表                                          │
│ [+ 添加候选]                                            │
│                                                         │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ # │ 候选Part              │ 条件公式       │ 优先级 │ │
│ ├───┼───────────────────────┼───────────────┼───────┤ │
│ │ 1 │ 电机-0.75kW (Part#11) │ 载重<=1000    │ 1     │ │
│ │ 2 │ 电机-1.5kW (Part#12)  │ 载重>1000     │ 2     │ │
│ │ 3 │ 电机-3.0kW (Part#13)  │ 载重>3000     │ 3     │ │
│ │   │                       │               │       │ │
│ │   [+ 添加]                │               │       │ │
│ └─────────────────────────────────────────────────────┘ │
│ 🔍 预览: 当前载重=1000 → 电机-0.75kW (Part#11)          │
└────────────────────────────────────────────────────────┘
```

**字段数：** N条规则，每条3个字段（Part + 条件 + 优先级）

### 4.4 🧬 变体生成（结构化JSON）

```
┌────────────────────────────────────────────────────────┐
│ 🧬 变体生成 - 从模板零件动态生成具体Part                     │
│                                                         │
│ 模板零件: [立柱-参数化 (Part#300)                ▼]      │
│                                                         │
│ 参数映射:                                                │
│ ┌──────┬────────────────────────┬──────────────────────┐│
│ │ 参数名 │ 公式/值               │ 预览值               ││
│ ├──────┼────────────────────────┼──────────────────────┤│
│ │ 高度  │ parent.货架高度        │ 2800                 ││
│ │ 材质  │ 'Q235'                │ Q235                 ││
│ │ 表面  │ '喷塑 RAL9016'        │ 喷塑 RAL9016         ││
│ │       │ [+ 添加参数]          │                      ││
│ └──────┴────────────────────────┴──────────────────────┘│
│                                                         │
│ 变体名称模板: 立柱-H{高度}        → 立柱-H2800           │
│                                                         │
│ [●] 配置确认时自动生成                                   │
│ [💾 保存变体映射]                                        │
└────────────────────────────────────────────────────────┘
```

**字段数：** 模板Part（1个选择器）+ 参数映射表（N行 × 2列）+ 名称模板（1个输入框）

### 4.5 📝 规格描述（结构化JSON）

```
┌────────────────────────────────────────────────────────┐
│ 📝 规格描述 - 定制件，不创建Part，写规格给车间/供应商         │
│                                                         │
│ 规格类型: [外协加工 ▼]  [自制件] [原材料] [客户提供]        │
│                                                         │
│ 规格字段:                                                │
│ ┌──────┬──────────────────────┬──────┬────────────────┐│
│ │ 字段名 │ 公式                 │ 单位  │ 预览值         ││
│ ├──────┼──────────────────────┼──────┼────────────────┤│
│ │ 材质  │ 'Q235'               │ —    │ Q235           ││
│ │ 长度  │ parent.货架高度+100   │ mm   │ 2900           ││
│ │ 截面  │ '80×40×3.0'         │ —    │ 80×40×3.0      ││
│ │ 表面  │ '喷塑 RAL9016'       │ —    │ 喷塑 RAL9016   ││
│ │       │ [+ 添加字段]         │      │                ││
│ └──────┴──────────────────────┴──────┴────────────────┘│
│                                                         │
│ 图纸号: 'DWG-' + param.订单号           → DWG-SO-005     │
│ 单价: param.长度 * 0.035 + 25          → ¥126.50         │
│                                                         │
│ 备注: 两端开安装孔，详见图纸                              │
│                                                         │
│ [💾 保存规格描述]                                        │
└────────────────────────────────────────────────────────┘
```

**字段数：** 类型选择 + 规格字段表（N行 × 3列）+ 图纸号 + 单价 + 备注

### 4.6 🏢 供应商选择

```
┌────────────────────────────────────────────────────────┐
│ 🏢 供应商选择规则                                         │
│ [+ 添加规则]                                             │
│                                                         │
│ ┌───┬──────────────────┬─────────────────┬───────────┐ │
│ │ # │ 条件公式          │ 供应商Part       │ 优先级   │ │
│ ├───┼──────────────────┼─────────────────┼───────────┤ │
│ │ 1 │ param.数量>1000  │ 供应商A-批量价   │ 1         │ │
│ │ 2 │ true             │ 供应商B-零售价   │ 2         │ │
│ │   │ [+ 添加]         │                 │           │ │
│ └───┴──────────────────┴─────────────────┴───────────┘ │
│ 🔍 预览: 当前数量=500 → 供应商B-零售价                    │
└────────────────────────────────────────────────────────┘
```

**字段数：** N条规则，每条3个字段

## 五、交互行为

### 5.1 展开/折叠

```
点击卡片任意位置 → 展开编辑器
点击展开按钮/再次点击 → 折叠
一次只能展开一个卡片（手风琴模式）
或允许多个同时展开（用户可配置）
```

### 5.2 模式切换

```
点击模式药丸 toggle → 启用/禁用该模式
  ●📐 = 激活  ○📐 = 未激活
  编辑器区动态切换显示对应编辑表单
  模式变更即时保存（调用updateBomItemMode API）
```

### 5.3 公式编辑

```
输入公式 → 失去焦点自动验证 → 显示结果
按 Ctrl+Enter → 预览计算
公式输入框支持快捷键：Tab插入参数名
```

### 5.4 保存

```
[💾 保存] 按钮明确定位在卡片编辑区底部
保存后卡片折叠，摘要更新
支持「保存并继续编辑」模式
```

### 5.5 键盘导航

```
↑↓ 在卡片间移动焦点
Enter 展开/折叠当前卡片
Tab 在编辑区的输入框间跳转
Esc 收起当前卡片
```

## 六、状态样式

### 6.1 卡片状态

```
正常:     白色背景，灰色边框
展开中:   蓝色左边框高亮，浅蓝背景
有公式:   公式摘要区蓝色文字
未配置:   公式摘要区灰色「未配置」
有错误:   红色边框，显示错误标记
已保存:   短暂显示绿色「✓已保存」提示
```

### 6.2 模式药丸颜色

```
📐 数量公式    → 蓝色
⚡ 条件包含    → 橙色
🎯 候选零件    → 绿色
🧬 变体生成    → 紫色
📝 规格描述    → 青色
🏢 供应商选择  → 琥珀色
```

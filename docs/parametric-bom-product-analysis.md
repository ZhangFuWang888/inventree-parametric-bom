## 二、当前存在的问题

### 🔴 P0 — 影响业务可用性

| 问题 | 影响 | 建议 |
|------|------|------|
| **❌ 无版本管理/历史追溯** | 改了BOM公式后回不去，没法对比差异 | 引入配置版本快照 + 变更记录 |
| **❌ 无审批流程** | 参数/BOM改完就直接生效，没有审核环节 | 编辑→审核→发布的3态工作流 |
| **❌ 无错误兜底** | 公式写错了生产时才发现 | 保存时自动校验+模拟测试 |

### 🟡 P1 — 影响效率

| 问题 | 影响 | 建议 |
|------|------|------|
| **⚠️ 无模板库** | 每个新产品重新配参数，没法复用 | 参数模板库 + 快速克隆 |
| **⚠️ 无批量操作** | 批量改参数/清空/复制只能手动一个个点 | 批量选择→编辑→应用 |
| **⚠️ 无高级搜索过滤** | 产品列表/参数列表多了不好找 | 全局搜索 + 高级过滤 |
| **⚠️ 无数据导出** | 参数配置/BOM公式无法导出为文档 | 参数报表 + BOM规范书导出 |

### 🔵 P2 — 影响体验

| 问题 | 影响 | 建议 |
|------|------|------|
| **🔹 iframe嵌入** | 页面通过iframe嵌入InvenTree，交互有割裂感 | 逐步原生化到React前端 |
| **🔹 手机端未适配** | 手机上操作参数/BOM很困难 | 移动端响应式适配 |
| **🔹 无操作指引** | 新用户不知道公式怎么用 | 内置帮助文档 + 公式示例库 |
| **🔹 加载速度** | 页面刷新重新加载全部数据 | 数据缓存 + 懒加载 |

## 三、建议开发的功能（按优先级排序）

### 🥇 Phase 2 — 企业级能力（1-2个月）

```
1. 📌 版本管理与审批工作流
   ├── BOM公式/参数每次编辑自动生成版本快照
   ├── 版本差异比较（高亮显示增删改）
   ├── 3态审批：编辑中 → 待审核 → 已发布
   └── 可回滚到任意历史版本

2. 📌 参数模板库
   ├── 预置行业常用参数模板（货架/柜体/机械结构等）
   ├── 从模板克隆参数配置到新产品
   ├── 共享参数集：团队可复用
   └── 模板市场（可选）
   
3. 📌 CRM集成 — 报价单生成
   ├── 从配置器直接生成PDF报价单
   ├── 自动计算：成本+利润率+批量折扣
   ├── 报价单模板自定义（公司Logo/条款）
   └── 报价历史管理
```

### 🥈 Phase 2 — 产品化能力（2-3个月）

```
4. 📌 客户自助配置门户

   ├── 客户选完参数→自动生成报价
   ├── 配置快照保存 + 分享
   ├── 客户确认后→自动生成内部订单
   └── 微信/H5适配（你的场景刚需！）

5. 📌 批量操作与数据管理
   ├── 批量编辑参数（全选→改范围/默认值）
   ├── BOM公式批量导入/导出（CSV/Excel）

6. 📌 可视化BOM树
   ├── 树形展开BOM层级（替代纯文本表格）
   ├── 颜色标记：条件禁用项 / 公式驱动 / 静态
```

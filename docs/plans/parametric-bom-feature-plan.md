# 参数化BOM系统 — 可实施工作计划

> **定位：** InvenTree 本身是通用ERP，这套参数化BOM插件给它增加了「按参数自动计算和展开BOM」的能力
> **代码规模：** 后端 ~7,500 行 Python + 前端 ~6,000 行 HTML/JS/CSS + 测试 ~4,000 行 = **~17,500 行**
> **测试：** 188/188 通过 ✅

---
